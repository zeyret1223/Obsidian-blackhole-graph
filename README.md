# Black Hole Graph

![license](https://img.shields.io/badge/license-MIT-blue.svg)
![obsidian](https://img.shields.io/badge/Obsidian-%E2%89%A5%201.0.0-7C3AED)

把你的笔记库渲染成一个黑洞吸积盘。

每篇笔记都是盘上的一个质点：链接越多的笔记离视界越近、转得越快，几乎没有链接的笔记则变成外围缓慢漂移的尘埃。整个盘会持续旋转，你可以拖动平移、滚轮缩放、点开任意一篇笔记。

![Black Hole Graph 预览：笔记按链接密度围绕中央黑洞排布](docs/preview.jpg)

## 特性

- **吸积盘布局**：按链接度数排名分配轨道半径，hub 笔记贴近黑洞，叶子笔记铺在外圈
- **只读安全**：仅通过 `metadataCache.resolvedLinks` 读取链接关系，不写入、不修改任何笔记
- **确定性布局**：基于笔记路径做哈希（FNV-1a + mulberry32），每次打开位置一致，不会乱跳
- **交互**：拖拽平移、滚轮缩放、单击打开笔记、`Ctrl` / `Cmd` + 单击在新标签页打开、双击复位视图
- **孤立笔记处理**：没有任何链接的笔记作为外围尘埃缓慢漂移，可单独关闭
- **纯 Canvas 2D**：无第三方依赖，不加载任何远程资源

## 安装

尚未上架 Obsidian 社区插件市场，手动安装：

1. 下载本仓库的 `main.js`、`manifest.json`、`styles.css`
2. 在你的笔记库中创建目录 `<你的库>/.obsidian/plugins/blackhole-graph/`
3. 把三个文件放进该目录
4. 打开 Obsidian → 设置 → 第三方插件 → 关闭「安全模式」→ 刷新已安装插件 → 启用 **Black Hole Graph**

## 使用

启用后有两种打开方式：

- 点击左侧边栏的圆点图标
- 命令面板（`Ctrl/Cmd + P`）搜索「打开黑洞图谱」

在视图中：

| 操作 | 效果 |
| --- | --- |
| 拖拽 | 平移视图 |
| 滚轮 | 以光标为中心缩放（0.3× – 6×） |
| 单击节点 | 打开该笔记 |
| `Ctrl` / `Cmd` + 单击 | 在新标签页打开 |
| 双击空白处 | 复位缩放与平移 |

## 设置

| 设置项 | 说明 |
| --- | --- |
| 旋转速度 | 吸积盘自转快慢 |
| 圆盘倾斜度 | 数值越小，盘面越扁（越接近侧视） |
| 圆盘旋转角度 | 整个盘面的朝向 |
| 节点大小 | 笔记质点的整体缩放 |
| 显示链接线 | 是否绘制笔记之间的连线 |
| 链接线亮度 | 连线的透明度 |
| 显示孤立笔记 | 无链接笔记是否作为外围尘埃出现 |
| 显示核心笔记名称 | 是否为最靠近黑洞的 10 个 hub 显示标题 |

## 兼容性

- 最低 Obsidian 版本：1.0.0
- 桌面端与移动端均可运行
- 笔记量在数千篇以内表现较好；更大的库建议调低「节点大小」并关闭「显示链接线」
